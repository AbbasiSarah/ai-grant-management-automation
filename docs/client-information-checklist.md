
# Client Information Checklist

## Purpose
Identify the information and documents needed from a client before preparing a grant application.

## Checklist

### Organization Information
- [ ] Legal name of the organization
- [ ] Organization type
- [ ] Country and region of registration
- [ ] Registration certificate or proof

### Project Information
- [ ] Project title
- [ ] Project description
- [ ] Problem the project aims to address
- [ ] Target beneficiaries
- [ ] Expected outcomes and impact

### Financial Information
- [ ] Total project budget
- [ ] Amount requested from the funder
- [ ] Budget breakdown
- [ ] Other funding sources, if applicable

### Application Documents
- [ ] Project proposal
- [ ] Detailed budget
- [ ] Proof of registration
- [ ] Any additional documents required by the funder

## AI Review Instructions

When reviewing client information:

1. Compare the available information with the grant requirements.
2. Identify missing information and documents.
3. Do not assume that missing information is available.
4. Do not invent organizational details, project facts, or financial figures.
5. Mark each item as Complete, Missing, or Needs Verification.
6. Ask clear questions for every missing or unclear requirement.
7. Distinguish mandatory grant requirements from general information that may be useful.

## Example Output

| Information | Status | Follow-up Question |
|---|---|---|
| Organization legal name | Missing | What is the organization's registered legal name? |
| Registration proof | Missing | Can you provide the organization's registration certificate? |
| Project description | Missing | What educational project are you planning? |
| Project budget | Missing | What is the estimated total project cost? |

## Important Note
This checklist is a starting point. The actual information required depends on the specific grant guidelines. A completed checklist does not guarantee eligibility or funding.
